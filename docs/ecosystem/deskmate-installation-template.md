# DeskMate installation guide template

Keep one guide per version and distribution when disk order, required ROMs, or installation commands differ. Link each guide from the [installation index](deskmate-installations.md) and map its Markdown source in the existing Eleventy [page map](../site/page-map.json). Use the [3.05 guide](deskmate-installation-305.md) as the first example.

## Release and evidence status

State the product and edition, observed launcher build, documented model or catalog number, source, and highest evidence stage. Link the primary experiment and state what ran. Cite manufacturer statements, contemporary observations, and project results at their first use. Use Oxford commas in public prose.

## Requirements and preparation

Record advertised and tested prerequisites separately. Include machine and BIOS, DOS version, RAM, display, floppy type, hard disk geometry, input, sound, and printer. For emulator tests pin source, build, ROM, settings, and baseline hashes. Identify working copies and their rollback source.

## Installation media

For each original give the source URL, checksum, size, collection date, media type, exact image/member path, disk number, and both the physical label and filesystem label where known. Record inferred completeness and list missing components. Keep original commercial bytes private.

## Install and configure

List the exact boot sequence, command or menu, prompt and media swap order, installation options and defaults, reset, and final directory. Mark which steps come from logs, manufacturer instructions, third-party notes, or static reconstruction. Record observed failures, workarounds, and separately tested alternatives.

## Verify startup and version

Give the launch commands and observed startup state. Identify the launcher and runtime files, startup settings, and a small hash-pinned installed file set. Record one native application check and any associated fixture. Distinguish first launch from later sessions.

## Illustrations and sources

Use reviewed captures with an alt description, caption, version, source hash, evidence checkpoint, and transformation recipe. Keep full-resolution derivatives accessible, and mark missing stages and the origin of any independent illustration. Register public images in the [site image manifest](https://github.com/smartyhall/deskmate-formats/blob/main/website/reference-images.json). Link relevant original Tandy materials by Faxback number, preserve attribution and rights, and follow [the Faxback documentation issue](https://github.com/smartyhall/deskmate-formats/issues/154) for faithful text and facsimiles.

## Gaps and next experiment

List unresolved prerequisites, incomplete media, and untested workflows. Propose a single bounded follow-up with expected evidence and rollback. Link the [installation roadmap](https://github.com/smartyhall/deskmate-formats/issues/153).
