# Experimental methodology

Keep original media immutable and working installations separate. Verify baseline
hashes/inventory, clone a disposable tree, change one controlled variable, visually
verify intended application values, exit cleanly, preserve a full snapshot/manifest,
and compare every byte and file. Distinguish absolute-offset changes from inferred
insertions in repetitive data. Record unexpected bytes as well as predictions.

Label evidence **confirmed**, **probable**, or **speculative**; final snapshots do
not prove transient implementation algorithms. Parser acceptance is not application
acceptance. Record negative/rejected layouts and known codec limits. Keep complete
screenshots, executables, images, installed snapshots and local paths in the private
archive; publish only rights-reviewed documentation and synthetic reproductions.

The packaging transition does not launch DeskMate or conduct E15. Historic Calendar
records are preserved in the imported specification rather than reinterpreted as
new experiments. An unchanged-event OK may be optimized as no disk write; byte
identity establishes no observed normalization, not a forced rewrite trace.
