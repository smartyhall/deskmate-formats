# Project

This section is about the work rather than the subject: how this reference is
researched and published, what state it is in, where it is going, and how to
contribute. It is public and linked from the main navigation, but it is
deliberately presented as secondary to the DeskMate history and technical
reference — a reader looking up a file format should not have to walk through
project planning to find it.

The project is an independent preservation effort. It is not affiliated with
Tandy or Radio Shack, and it does not redistribute commercial software.

## Sources and evidence boundaries

Project pages describe intent and method. They are not evidence about DeskMate
itself, and they do not override the technical or historical pages. Planning
material is kept accessible but is not presented as a specification.

Licensing is recorded in the repository rather than restated page by page.
Third-party material is published only where the project holds the rights or
where a documented grant applies, and attribution never claims rights the
project does not hold.
