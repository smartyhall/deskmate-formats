For binary parsing/writing, check bounds, offsets, record sizes,
integer signedness, endianness, truncation, malformed input, unknown
byte preservation and round-trip fidelity. Distinguish inferred fields
from demonstrated layouts. For lab/control code, check ownership,
authentication, pacing, timeouts, observable state and uncertain
mutation handling; never recommend bypassing live-launch gates.
