# Shared quadratic arc projection

The [manifest](manifest.json) records all 23 fresh native reopens.
Each Normal-zoom crop matched the corresponding baseline crop
byte-for-byte. The scalable projection now draws the two chart arcs
and two workshop door swings. Each uses the native three-point
quadratic geometry documented in the [arc study](../../../../docs/research/draw-geometry-20261119.md).
This milestone preserves the Chromium viewport and baseline metric
definitions. Stroke weights, dash patterns, patterned fills and external
fonts remain approximations or omissions in the scalable projection.
